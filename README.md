# The Cleaner — ذا كلينر (mock app prototype)

Interactive UX prototype (v2.0) with **mock data only**. Sign-in uses an on-screen demo code (no SMS). Bookings, driver collection, bills, payments, wallet and compensation are simulated: nothing is charged, no card details are collected, and nothing is connected to CleanCloud, Wafeq or a payment gateway. Support channels are not configured.
